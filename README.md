# چسوكتي — Cinematic Love Experience

تجربة ويب سينمائية رومانسية فاخرة من صفحة واحدة، مهداة إلى **چسوكتي**.

## التشغيل

افتح `index.html` مباشرة في أي متصفح حديث (Chrome / Safari / Firefox / Edge).
لا يحتاج إلى Node.js ولا build ولا خادم — كل المكتبات تُحمَّل من CDN.

> ملاحظة: بعض المتصفحات تقيّد `file://` مع الـ ES Modules.
> إن واجهت مشكلة، شغّل خادمًا محليًا بسيطًا:
> ```
> python3 -m http.server 8000
> ```
> ثم افتح `http://localhost:8000`.

## هيكل المشروع

```
Jusokti_Love_Experience/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── fonts/    (الخطوط من Google Fonts عبر CDN)
    └── audio/
        └── music.mp3   ← ضع ملف الموسيقى الخاص بك هنا
```

## استبدال الموسيقى

ضع ملف MP3 باسم `music.mp3` داخل `assets/audio/`.
زر الموسيقى في الأسفل لا يعمل تلقائيًا — يحتاج تفاعل المستخدم.

## التقنيات

- Three.js (WebGL + Post-processing: Bloom)
- GSAP (Timeline + Easing سينمائي)
- خطوط عربية فاخرة: Aref Ruqaa, Amiri
